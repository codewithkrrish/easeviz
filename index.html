How it works

    

    

      

        
1. Shape the curve

        
Drag the two handles. The horizontal axis is time, the vertical axis is progress. A steep middle means a fast middle.

      

      

        
2. Feel it move

        
The dot, the card, and the bar all run on your exact curve — solved in JavaScript with the same math browsers use.

      

      

        
3. Copy and go

        
Grab the CSS, the Tailwind class, or the sampled @keyframes. No account, no build step, no install.

      

    

  


  
  

    

      
Good to know

    

    

      

        Why can't I drag the handles for bounce and elastic?
        
A cubic-bezier has exactly two control points, and its value can only move in one direction per axis. Bounce changes direction several times and elastic oscillates past the end — no single bezier can draw that. Those two are sampled keyframes instead, and the code tab gives you the real @keyframes.

      

      

        Why do the handles allow y values below 0 and above 1?
        
That's overshoot — the curve goes past its target and comes back, which is what makes "back" easings feel springy. The editor shows down to −0.6 and up to 1.6 so you can see the whole overshoot.

      

      

        Which easing should I use for UI that appears?
        
Ease-out-cubic is the safe default — quick start, soft landing. Ease-out-back when you want a playful pop. Avoid ease-in for things appearing; slow starts feel laggy when you're waiting on something.

      

      

        Does it work offline?
        
Yes. No fonts, scripts, or images are loaded from anywhere else. Open index.html from disk or serve the folder — everything runs locally.
